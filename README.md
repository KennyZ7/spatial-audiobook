# 循意生境 空间有声书工作台

在本机浏览器中制作短篇空间有声书：小说文本、可编辑声音事件、多角色配音、实测 HRTF 双耳渲染和 WAV 导出。电脑完成生成，普通双耳耳机试听。

## 启动与第一轮试听

首次使用请先按下文安装依赖与素材。已有安装可双击根目录 `启动工作台.cmd`，或访问 <http://127.0.0.1:8765>。

1. 打开“空间试听”，选择 H3/H4/H5，先降低耳机音量，再试听前后、上下、左右、远近与移动。
2. 可启用盲听，提交实际听到的方向、评分和备注；点“将此配置用于当前工程”。**自动化测试的听感记录标为“自动化界面验证”，不代表真实用户评价。**
3. 创作工作台预置“十一点十七分”示例，已生成免费系统配音成品。该示例使用 Windows 系统音色，无法使用角色音色时回退旁白；它用于流程验证，不代表正式情感配音质量。
4. 配置 API 后，载入新的悬疑示例，点“生成声音脚本”，再“合成并渲染”。500字左右先做一次小样。

## 配置模型与控制费用

在“服务与费用”中填写 DeepSeek 和 MiniMax 的普通按量计费 API Key。密钥只由本机后端保存，不回显；留空保留旧密钥。也可以通过 `DEEPSEEK_API_KEY`、`MINIMAX_API_KEY` 环境变量提供，环境变量优先。

- 默认 DeepSeek 模型为 `deepseek-v4-flash`，可修改；配音默认 `speech-2.8-hd`，可切换较低成本的 Turbo。
- DeepSeek 费率默认输入10元、输出30元/百万 token，是保守的预算估算占位值，**不是官方报价**。先在官方页面核对并修改，再勾选费率确认。
- MiniMax 2026-09-08官方说明：HD 3.5元/万计费字符、Turbo 2元/万计费字符，汉字计2个字符。实现按此规则估算并加10%余量，成功后优先使用响应中的计费字符数。
- 默认累计保护额度50元，可调低，不能在界面调高。初次只充值最小必要金额；不使用音色克隆或音色设计收费接口。最低充值金额需在你自己的账户结算页确认。
- 每次请求先登记费用预留，再调用。网络失败且无法确定计费结果时不释放预留。调用不自动重试，避免不明扣费；重试会利用已成功的缓存。
- 自动化测试使用模拟接口；本地示例另有实际生成记录。每位协作者使用自己的密钥，实际费用以供应商账单为准。

本机配置位于 `data/settings.json`，不要把它或包含密钥的截图分享出去。程序只绑定 `127.0.0.1`，不用于直接公开到互联网。

## 创作和修改

- **忠实朗读**：系统按原文跨度生成台词，不采用模型的文字改写。角色识别依赖模型或手动修正。原文中的引号和标点保留。
- **适度广播剧化**：逐片段保存原文与改编；删除的叙述保留为禁用事件，可展开“查看原文 / 恢复”。不保证模型绝不误改，成品前请检查。
- **免费分句**：完全本地，只生成旁白草稿，不冒充 AI 理解或自动改编。可以添加角色并手动指定说话人。
- 点击事件可编辑台词、音色、情绪、语速、素材、音量、时间和位置；轨迹每行是 `时间,x,y,z`，首点0秒，后续递增，单位米和秒。
- 坐标：右 `+x`，上 `+y`，前 `+z`。声源避免放在听众头部中心；低于0.15米内部使用前方0.15米处理。
- 音效可置于句前、句后、句内偏移，或设绝对开始时间。句内以秒修正，不是自动逐字对齐。
- 修改空间位置、音量、轨迹后点“仅重新渲染”；它严格禁止付费合成。缺少配音缓存则提示先合成。修改台词、情绪、语速、音色只使对应缓存失效。
- 可上传录音替代配音。如果事件已选择录音，修改台词不会改变该录音；清空“录音替代配音”后才使用模型。
- 修改原文或切换模式会清空当前脚本，历史成品继续保留。工程版本冲突会要求重新打开；运行任务期间禁止保存同一工程。
- 下载工程与分轨包包含原始工程、实际时间线、渲染指标、干声分轨及最终混音。压缩包用于归档和研究；首版没有 ZIP 导入功能。继续编辑使用本机工程列表。

## 空间渲染与边界

`studio/audio.py` 是独立 DSP 基线，不依赖模型 API。SOFA 导入转换坐标，使用3近邻反距离方向插值和512采样跳步的加窗重叠相加双耳卷积。旁白保持居中，其他声音参与定位；循环环境音和音乐在人声时平滑压低。

房间效果是轻量多抽头反射近似，不是实测房间、完整声线追踪或个体化 HRTF。方向插值尚未采用显式 ITD 对齐，可能造成部分方向的谱形变化；这是后续可评估的基线局限。上下、前后感觉取决于听众和耳机，最终需要你试听。

首版单输入最大2000字、220个自动文本片段、8个自动角色、最多8个同时活动的点声源；成品最大20分钟。长背景声可在180秒以内设置并循环。音乐默认关闭。

生成输出为48 kHz、24位双声道 WAV。浏览器直接播放同一个 WAV，不重复叠加浏览器空间化。工程渲染是离线处理；此处的实时系数不等于音频设备播放延迟。

## 开发、安装与测试

Windows / Python 3.12：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
.venv/Scripts/python.exe -m uvicorn studio.app:app --host 127.0.0.1 --port 8765
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/benchmark.py
```

可选免费演示生成：`.venv/Scripts/python.exe scripts/seed_demo.py`，仅支持安装中文系统语音的 Windows。会覆盖 ID 为 demo_suspense 的工程；请先备份或在新安装中运行。

主要目录：`studio/` 后端与DSP，`web/` 前端，`scripts/` 安装/演示/基准，`tests/` 测试，`data/` 本机工程与资源（不纳入版本控制）。运行时任务恢复会将上次中断任务标为失败；再次提交即可复用缓存。
